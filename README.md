# 🔍 SEO & 웹접근성 체크 북마클릿 툴

북마클릿(bookmarklet)을 통해 웹사이트의 SEO와 웹 접근성 항목을 간편하게 진단할 수 있는 툴입니다. 별도의 설치 없이 북마클릿을 클릭만 하면 현재 페이지를 분석하고 진단 결과를 한눈에 확인할 수 있습니다.

## 📢 최신 업데이트

- **UI/UX 대폭 개선**: 전체 UI를 **shadcn/ui 스타일**로 개편하여 더욱 모던하고 일관된 사용자 경험을 제공합니다.
- **성능 최적화**: JavaScript 코드 최적화 및 비동기 처리를 강화하여 북마클릿 실행 시 **로딩 속도와 반응성을 크게 향상**시켰습니다.
- **고급 분석 기능 강화**:
    - **페이지 성능 (Core Web Vitals)**: LCP, FID, CLS 등 주요 성능 지표 측정 기능(브라우저 환경에 따라 제한적일 수 있음) 또는 관련 도구 안내를 제공합니다.
    - **모바일 친화성**: 뷰포트, 터치 타겟 크기, 글꼴 크기 등 더 상세한 기준으로 분석합니다.
- **소셜 미리보기 개선**: Open Graph 및 Twitter Card 분석 결과를 실제 공유되는 카드 형태와 유사하게 **시각적으로 개선**했습니다.
- **내보내기 기능 확장**:
    - **개요 탭 CSV 내보내기**: 페이지의 주요 개요 정보를 CSV 파일로 저장할 수 있습니다.
    - **전체 보고서 PDF 저장**: 현재 분석된 모든 탭의 내용을 하나의 PDF 파일로 저장(브라우저 인쇄 기능 활용)할 수 있는 버튼이 추가되었습니다.
- **코드 일관성 및 가독성 향상**: 전반적인 코드 구조를 검토하고 개선하여 유지보수성을 높였습니다.

## 📌 목적

이 툴은 다음과 같은 목적을 가지고 개발되었습니다:

- 웹사이트의 주요 SEO 요소 및 웹 접근성 요소를 빠르게 진단
- 개발자, 디자이너, 기획자 누구나 쉽게 사용할 수 있도록 북마클릿 형태 제공
- 설치나 로그인 없이 실시간으로 진단 가능

## 🎯 주요 기능

### ✅ 진단 탭 구성

모든 분석 결과는 개선된 UI의 탭을 통해 정리되어 표시됩니다:

1.  **개요 (Overview)**
    *   페이지 타이틀 (길이 및 적절성 평가)
    *   메타 디스크립션 (길이 및 적절성 평가)
    *   URL 및 색인 가능 여부 (Robots 태그 기반)
    *   Canonical URL 확인 및 자기 참조 여부
    *   Robots / X-Robots-Tag 유무 및 내용
    *   키워드 메타 태그 유무
    *   본문 단어 수 및 콘텐츠 충분성 평가
    *   HTML 언어 (lang) 속성 확인
    *   Hreflang 설정 정보
    *   **내보내기**: 개요 정보 CSV 파일로 저장

2.  **제목 구조 (Headings)**
    *   H1 ~ H6 태그 사용 개수 및 분포
    *   제목 구조의 논리적 순서 진단 (예: H1 다음 H3 사용 등)
    *   내용이 없는 빈 제목 요소 검출
    *   HTML 문서 개요 시각화

3.  **문서 구조 (Document Structure)**
    *   주요 시맨틱 태그 (Header, Nav, Main, Footer, Article, Section, Aside) 사용 현황
    *   문서 구조의 중첩 관계 및 계층 시각화 (접기/펼치기 기능 제공)
    *   시맨틱 태그 사용에 대한 간략한 접근성 점수 제공

4.  **링크 (Links)**
    *   총 링크 수 및 고유 링크 수
    *   내부/외부 링크 구분 및 비율 시각화
    *   `href` 속성이 없거나 비정상적인 링크 식별
    *   새 창(`target="_blank"`)으로 열리는 링크의 `rel="noopener noreferrer"` 속성 검사
    *   "여기", "클릭" 등 일반적인 링크 텍스트 사용 여부 검사
    *   **내보내기**: 내부/외부/전체 링크 리스트 CSV 파일로 저장

5.  **이미지 (Images)**
    *   이미지 총 개수 및 형식(JPG, PNG, GIF, WebP, SVG, AVIF 등)별 분류
    *   `alt` 속성 누락 또는 빈 이미지 식별 (장식용 이미지 구분)
    *   `alt` 텍스트 길이 적절성 (너무 길거나 짧은 경우)
    *   `width`/`height` 속성 누락으로 인한 레이아웃 이동(CLS) 유발 가능성 검사
    *   표시 크기 대비 원본 이미지 크기 과대 여부 (성능 저하 요인)
    *   `loading="lazy"` 속성 사용 현황 (첫 화면 이후 이미지 대상)
    *   반응형 이미지 속성 (`srcset`, `sizes`) 사용 여부
    *   **내보내기**: 모든 이미지 정보 또는 문제 있는 이미지 정보 CSV 파일로 저장

6.  **스키마 (Schema)**
    *   JSON-LD, Microdata, RDFa 형식의 Schema.org 마크업 식별
    *   페이지 내 사용된 주요 스키마 타입(@type) 수집 및 표시
    *   스키마 구조 시각화 (아코디언 형태로 제공)
    *   스키마 유효성 검사 도구 링크 제공

7.  **소셜 (Social)**
    *   Open Graph (og:title, og:description, og:image 등) 메타 태그 상세 분석
    *   Twitter Card (twitter:card, twitter:title 등) 메타 태그 상세 분석
    *   **시각적 미리보기**: Facebook/OpenGraph 및 Twitter 공유 시 카드 형태 미리보기 제공
    *   소셜 태그 최적화 권장사항 및 관련 검증 도구 링크 제공

8.  **고급 설정 (Advanced)**
    *   **페이지 성능**: Core Web Vitals (LCP, FID, CLS, FCP) 지표 측정 시도 및 결과 표시 (브라우저 환경에 따라 제한적일 수 있으며, 미지원 시 안내)
    *   **모바일 친화성**: 뷰포트 설정 (width, initial-scale, user-scalable), 터치 타겟 크기, 가독성 있는 글꼴 크기, 콘텐츠 너비 등 상세 분석
    *   **Hreflang 분석**: 다국어 설정(hreflang 태그)의 존재 유무 및 세부 정보 표시
    *   **키워드 분석**: 페이지 내 주요 키워드 및 빈도수 표시 (키워드 클라우드 형태)
    *   **내부 링크 구조**: 주요 내부/외부 링크, JS 이벤트 링크, nofollow 링크 개수 요약

## 🧑‍💻 사용 방법

1.  북마클릿 스크립트를 브라우저의 북마크바에 등록합니다.
2.  분석하고 싶은 웹페이지에 접속합니다.
3.  북마크바에서 해당 북마클릿을 클릭하면, 페이지 우측에 세련된 탭 기반 UI로 진단 결과가 즉시 출력됩니다.

진단 결과는 각 항목별로 **`양호`, `주의`, `오류`** 등의 상태로 명확하게 표시되며, 문제 해결을 위한 설명과 가이드가 함께 제공됩니다. **"전체 보고서 PDF 저장"** 버튼 또는 각 탭별 **CSV 내보내기** 버튼을 통해 분석 결과를 저장할 수 있습니다.

## 🚀 시작하기

### 서버 설정 및 실행

1. 이 저장소를 클론합니다.

```bash
git clone https://github.com/your-username/seox.pointer.git
```

2. 프로젝트 폴더로 이동합니다.

```bash
cd seox.pointer
```

3. 필요한 패키지를 설치합니다.

```bash
npm install
```

4. 서버를 시작합니다.

```bash
npm start
```

5. 브라우저에서 `http://localhost:3000`으로 접속합니다.

### 북마클릿 설치 및 사용

1. `http://localhost:3000` 페이지에서 북마클릿 링크를 북마크바에 드래그합니다.
2. 분석하고 싶은 웹페이지로 이동합니다.
3. 북마크바에서 방금 저장한 북마클릿을 클릭합니다.
4. 북마클릿이 해당 페이지를 분석하고 결과를 화면 우측에 표시합니다.

### 서버 배포

실제 사용을 위해서는 서버를 배포해야 합니다:

1. Vercel, Netlify, Heroku 등의 호스팅 서비스에 배포합니다.
2. 배포 후 `bookmarklet.js` 파일의 URL 값을 실제 서버 URL로 변경합니다.
3. 변경된 북마클릿 코드를 사용자에게 제공합니다.

## ⚠️ 제약 사항 및 주의

- 북마클릿은 보안 정책(CORS 등)에 따라 일부 기능 제한 가능
- iframe으로 구성된 사이트에서는 정상 동작하지 않을 수 있음
- 서버가 실행 중이고 접근 가능해야 북마클릿이 작동함
- 고급 웹 접근성 진단 기능(스크린리더, 키보드 시뮬레이션 등)은 미포함
